# FollowCore-CAN

CAN bus edition. Current controller: ESP-V3.003 / ESP32-S3-WROOM-1-N16R8.
Paired driver: supported STM32F303-based project hardware.

Release metadata is stored under `releases/<version>/`. Actual BINs and browser
applications are assets in [GitHub Releases](https://github.com/sapphiresaiv/followcore-firmware/releases).
Do not use these images for Pulse or EtherCAT hardware.
