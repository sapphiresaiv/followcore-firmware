# Security reports

Send security-sensitive findings to sapphiresaiv@gmail.com rather than posting
credentials, signing material, or exploitable details in a public issue.
Include affected hardware/firmware versions, impact, and safe reproduction
steps. Do not test against another user's equipment without authorization.

Release candidates are evaluation builds, not a guaranteed support or security
service. Firmware signing private keys are never distributed. SHA256 checks
detect changed bytes; they do not replace firmware signature verification.
